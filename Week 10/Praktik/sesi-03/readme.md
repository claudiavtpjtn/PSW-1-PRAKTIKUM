1. FORM INPUT

Pada bagian 3. Form Input, saya mempelajari cara menambahkan form ke dalam halaman web agar pengguna dapat memasukkan nama peserta baru ke dalam daftar yang sudah dibuat pada Sesi 2. Kode `<form id="form-peserta">` digunakan untuk membuat form dengan ID `form-peserta` agar nantinya dapat dipanggil menggunakan JavaScript. Selanjutnya, `<label for="nama">Nama (wajib)</label>` digunakan untuk memberikan keterangan pada kolom input bahwa nama harus diisi. Kode `<input id="nama" name="nama" required>` merupakan tempat pengguna mengetikkan nama peserta. Kemudian, `<button type="submit">Tambah</button>` digunakan untuk membuat tombol Tambah yang berfungsi mengirimkan nama yang sudah dimasukkan. Dengan adanya form ini, pengguna dapat menambahkan peserta secara langsung melalui halaman web tanpa harus mengubah kode program.

Kemudian, `FormData(form).get("nama")` digunakan untuk mengambil nama yang diketik pengguna, sedangkan `trim()` berfungsi menghapus spasi yang tidak diperlukan di awal dan akhir nama. Setelah itu, `if (!nama)` digunakan untuk memeriksa apakah nama masih kosong. Jika nama belum diisi, program akan menampilkan pesan bahwa nama harus diisi dan tidak melanjutkan proses penambahan. 3. TOMBOL HAPUS SAAT RENDER

Pada bagian ini, saya mempelajari cara membuat tombol Hapus secara otomatis untuk setiap peserta yang ditampilkan dalam daftar. Kode `document.createElement("button")` digunakan untuk membuat elemen tombol baru menggunakan JavaScript. Selanjutnya, `btn.type = "button"` berfungsi menentukan jenis tombol agar ketika diklik tidak dianggap sebagai tombol untuk mengirimkan form. Kode `btn.textContent = "Hapus"` digunakan untuk memberikan tulisan Hapus pada tombol tersebut. Kemudian, `btn.dataset.id = String(p.id)` digunakan untuk menyimpan ID peserta ke dalam atribut `data-id` pada tombol. ID ini penting karena setiap peserta memiliki ID yang berbeda, sehingga program dapat mengetahui peserta mana yang akan dihapus ketika tombol diklik. Setelah tombol selesai dibuat, `li.append(btn)` digunakan untuk memasukkan tombol Hapus ke dalam elemen daftar peserta. Dengan cara ini, setiap nama peserta yang ditampilkan akan memiliki tombol Hapus masing-masing, sehingga pengguna dapat menghapus peserta yang diinginkan tanpa mengganggu data peserta lainnya.

4. DELEGATION DAN PENGUJIAN

Pada bagian 4. Delegation dan Pengujian, saya mempelajari cara menggunakan event delegation agar semua tombol Hapus dapat bekerja dengan cukup menggunakan satu event listener pada elemen daftar peserta. Teknik ini berguna karena tombol Hapus dibuat secara langsung melalui JavaScript, sehingga tombol yang baru ditambahkan tetap dapat menjalankan fungsinya tanpa harus memasang event listener satu per satu. Ketika pengguna mengklik area daftar, kode `event.target.closest("button[data-id]")` digunakan untuk mencari tombol Hapus yang diklik berdasarkan atribut `data-id`. Selanjutnya, `if (!btn || !daftar.contains(btn)) return` digunakan untuk memastikan bahwa elemen yang diklik benar-benar merupakan tombol yang berada di dalam daftar. Jika bukan, program akan menghentikan proses agar tidak menjalankan perintah yang tidak diperlukan. Jika tombol ditemukan, `Number(btn.dataset.id)` digunakan untuk mengambil ID dari tombol dan mengubahnya menjadi angka. Setelah itu, `peserta.filter(p => p.id !== id)` digunakan untuk menyaring data peserta dengan cara mempertahankan peserta yang ID-nya tidak sama dengan ID tombol yang diklik. Dengan demikian, peserta yang dipilih akan dikeluarkan dari array, sedangkan peserta lainnya tetap tersimpan. Terakhir, `render()` dipanggil kembali agar tampilan daftar pada halaman web diperbarui sesuai data terbaru. Melalui bagian ini, saya memahami bahwa event delegation dapat membuat pengelolaan tombol menjadi lebih sederhana, terutama ketika elemen dibuat dan ditambahkan secara dinamis menggunakan JavaScript.
