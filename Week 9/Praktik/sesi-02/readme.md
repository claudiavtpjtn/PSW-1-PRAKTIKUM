 > eksperimen string dan number
Pada percobaan ini, saya menguji perbedaan antara String dan Number menggunakan kode const teks = "2";, kemudian membandingkan hasil teks + 1 dengan Number(teks) + 1. Variabel teks menyimpan nilai "2" yang termasuk String karena ditulis menggunakan tanda petik. Ketika dijumlahkan dengan angka 1 tanpa konversi, hasilnya adalah 21. Hal ini terjadi karena JavaScript menganggap operasi tersebut sebagai penggabungan teks, bukan penjumlahan angka. Selanjutnya, saya menggunakan Number(teks) untuk mengubah nilai "2" menjadi angka 2 sehingga hasil penjumlahannya menjadi 3. Saya juga menggunakan typeof untuk mengetahui tipe data. Hasilnya menunjukkan bahwa "2" bertipe string, sedangkan 2 bertipe number. Selain itu, saya mencoba Number("abc") yang menghasilkan NaN karena teks tersebut tidak bisa diubah menjadi angka. Saya kemudian menggunakan Number.isFinite() untuk memeriksa apakah hasil konversi merupakan angka yang valid dan terbatas. Hasilnya false karena nilai tersebut adalah NaN. Dari percobaan ini, saya memahami bahwa bentuk nilai yang terlihat sama belum tentu memiliki tipe data yang sama. Kesalahan dalam memahami tipe data bisa menyebabkan hasil perhitungan tidak sesuai. Oleh karena itu, data perlu diperiksa dan dikonversi terlebih dahulu sebelum digunakan dalam perhitungan. Saya juga mengetahui bahwa Number("") menghasilkan 0, sehingga input kosong tidak boleh langsung dianggap sebagai input angka yang benar.

 > eksperimen jumlah 1-5 dan harga tetap tiket
Pada percobaan ini, saya membuat program untuk memeriksa apakah jumlah tiket yang dimasukkan sesuai dengan aturan, yaitu minimal 1 dan maksimal 5. Program menggunakan variabel jumlah dengan nilai yang dikonversi melalui Number(). Setelah itu, saya menggunakan if untuk memeriksa tiga kondisi, yaitu !Number.isInteger(jumlah), jumlah < 1, dan jumlah > 5. Kondisi pertama digunakan untuk memeriksa apakah jumlah bukan bilangan bulat. Fungsi Number.isInteger() menghasilkan true jika nilainya merupakan bilangan bulat, sedangkan tanda ! membalik hasilnya. Kondisi kedua memeriksa apakah jumlah kurang dari 1, dan kondisi ketiga memeriksa apakah jumlah lebih dari 5. Ketiga kondisi tersebut menggunakan operator || yang berarti ATAU. Artinya, jika salah satu kondisi benar, program akan menampilkan pesan "Jumlah tidak valid". Jika semua kondisi salah, program menjalankan bagian else dan menghitung total harga dengan mengalikan jumlah tiket dengan 10.000. Saya mencoba beberapa nilai seperti 0, 1, 5, 6, 1.5, dan "abc". Hasilnya, nilai 1 dan 5 diterima karena sesuai aturan, sedangkan nilai lainnya ditolak. Ketika "abc" dikonversi menggunakan Number(), hasilnya menjadi NaN. Nilai tersebut bukan bilangan bulat sehingga kondisi pertama menjadi true dan program masuk ke bagian if. Hal yang saya pelajari dari percobaan ini adalah program tidak boleh langsung menghitung semua input yang diberikan pengguna. Input harus diperiksa terlebih dahulu agar data yang tidak sesuai aturan tidak ikut diproses. Dengan begitu, conditional bukan hanya digunakan untuk memilih perintah, tetapi juga menjaga agar proses dalam program berjalan sesuai ketentuan.

 > Eksperimen loop koleksi
 Pada percobaan ini, saya menggunakan array untuk menyimpan beberapa judul, yaitu "HTML", "CSS", dan "Audit". Array merupakan tempat untuk menyimpan beberapa data dalam satu variabel. Setelah membuat array dengan nama judul, saya menggunakan perulangan for...of untuk membaca setiap data dan menampilkannya menggunakan console.log(item). Pada perulangan tersebut, item berfungsi sebagai variabel sementara yang menyimpan nilai yang sedang dibaca. Hasilnya, HTML, CSS, dan Audit muncul secara berurutan di Console. Hal ini terjadi karena perulangan membaca setiap isi array satu per satu sampai semua data selesai diproses. Saya kemudian mencoba menggunakan array kosong dengan kode const judul = [];. Hasilnya tidak ada tulisan yang muncul karena array tersebut tidak memiliki data untuk dibaca. Setelah menambahkan "JavaScript" sebagai data keempat, hasil yang muncul juga bertambah menjadi empat judul. Dari percobaan ini, saya memahami bahwa for...of memudahkan kita mengolah banyak data tanpa harus menuliskan perintah yang sama untuk setiap data. Saya juga mengetahui bahwa jumlah pengulangan bergantung pada banyaknya data yang tersedia. Jika array kosong, perulangan tidak menghasilkan keluaran. Hal ini menunjukkan bahwa sebelum melakukan perulangan, kita perlu memahami data yang akan diproses agar tidak salah memperkirakan hasil program.
