1. Tujuan
Praktikum ini bertujuan untuk mengembangkan halaman web dari praktikum W04S02. Pada praktikum ini, saya mempelajari bagaimana melakukan perubahan pada struktur HTML dan CSS agar tampilan halaman menjadi lebih rapi dan mudah diatur.
Selain itu, praktikum ini juga bertujuan untuk memahami penggunaan CSS variables, pengaturan ukuran halaman, box model, tipografi, serta pengaturan fokus pada input dan tombol. Perbandingan dengan W04S02 dilakukan untuk melihat perubahan yang terjadi setelah halaman dikembangkan.
Pengujian dilakukan menggunakan browser dan DevTools untuk memastikan perubahan yang dibuat benar-benar terlihat dan berjalan sesuai dengan yang diharapkan.

2. Penjelasan Perubahan
Pada W04S03, halaman dari W04S02 dikembangkan dengan beberapa perubahan pada HTML dan CSS. Pada bagian HTML, ditambahkan header agar bagian awal halaman lebih jelas dan memiliki susunan yang lebih teratur.
Pada bagian CSS, dilakukan beberapa perubahan seperti pengaturan lebar bagian utama halaman, penggunaan CSS variables, pengaturan box-sizing, serta pengaturan ukuran dan jarak tulisan. Selain itu, input dan tombol diberikan pengaturan fokus agar pengguna dapat mengetahui bagian yang sedang dipilih.
Jika dibandingkan dengan W04S02, W04S03 masih menggunakan sebagian besar struktur dan tampilan sebelumnya. Perbedaannya lebih banyak terdapat pada tambahan pengaturan CSS yang membuat halaman lebih rapi dan mudah dikontrol.

3. Hasil Uji
Berdasarkan pengujian yang dilakukan, halaman W04S03 berhasil dibuka melalui browser dan stylesheet berhasil diterapkan pada halaman. Perubahan pada HTML dan CSS juga dapat terlihat secara langsung.
Pada perbandingan ukuran elemen, W04S03 memiliki pengaturan box-sizing yang membuat ukuran elemen lebih mudah dikontrol karena padding dan border ikut diperhitungkan dalam ukuran kotak.
Pada bagian layout, W04S03 memiliki pengaturan lebar pada bagian utama halaman sehingga isi tidak terlalu lebar dan tetap berada di tengah. Pengaturan tulisan juga dibuat lebih teratur sehingga lebih nyaman dibaca.
Selain itu, CSS variables berhasil digunakan untuk menyimpan beberapa nilai seperti warna dan jarak. Input dan tombol juga memiliki tanda fokus ketika dipilih. Hasil pengujian diperiksa menggunakan browser dan DevTools untuk memastikan perubahan yang terjadi sesuai dengan pengaturan yang dibuat.
