1. Mengapa telepon bukan kuantitas number?
    Telepon bukan termasuk kuantitas number karena nomor telepon dapat memiliki simbol seperti tanda “+” di depannya. Selain itu, nomor telepon tidak digunakan untuk melakukan perhitungan, sehingga lebih tepat dianggap sebagai character/string daripada angka.
2. Apa beda label pilihan dan legend kelompok?
    Label digunakan untuk memberi keterangan pada sebuah input dan biasanya dapat ditekan untuk langsung mengarah ke input tersebut. Sedangkan legend digunakan sebagai judul atau keterangan untuk mengelompokkan beberapa pilihan atau input yang berada dalam satu kelompok.
3. Apa beda id dan name?
    ID digunakan sebagai penanda khusus untuk membedakan suatu input dengan input lainnya, sedangkan name digunakan sebagai nama dari data input yang akan dikirim ketika data formulir diproses atau disimpan ke database.
4. Apa yang terjadi pada checkbox tidak dicentang?
    Jika checkbox tidak dicentang, maka nilainya dianggap false atau tidak aktif. Pada saat formulir dikirim, checkbox tersebut biasanya tidak mengirimkan nilai ke server atau database karena tidak dalam kondisi dipilih.
